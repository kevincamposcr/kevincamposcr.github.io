# Kevin Campos · Diseño web

Portafolio y página de servicios de diseño web para negocios en Costa Rica.

## Contenido

| Carpeta / archivo | Qué es |
|---|---|
| `index.html` | Página principal: servicios, precios, proceso, sobre mí y contacto |
| `demos/soda-la-esquina/` | Demo: soda con menú y pedidos express por WhatsApp |
| `demos/barberia-norte/` | Demo: barbería con precios y reserva de citas |
| `demos/veterinaria-patitas/` | Demo: veterinaria con citas, emergencias y consejos |
| `demos/taller-hermanos-solis/` | Demo: taller mecánico bilingüe (ES/EN) con cotizaciones |

> Los negocios de las demos son ficticios y se usan solo para mostrar el trabajo.

## Cómo editar

- **WhatsApp:** en `index.html`, cambie `const WHATSAPP = "50670323812"`. En cada demo, cambie `const KEVIN_WA`.
- **Precios:** busque la sección `id="paquetes"` en `index.html`.
- **Foto:** suba una foto llamada `foto.jpg` a la raíz y quite el comentario de la etiqueta `<img>` en la sección "Sobre mí".
- **Agregar un trabajo nuevo:** cree una carpeta dentro de `demos/` con su `index.html` y agréguela a la lista `TRABAJOS` en `index.html`.

## Publicación

El sitio se publica gratis con **GitHub Pages** desde la rama `main`.
